# Suggested team split (3 people)

## Person 1: ML / NLP
- Dataset sourcing and licensing.
- Annotation guide and label quality.
- TF-IDF baseline, Linear SVM comparison, evaluation, error analysis.
- Replace synthetic seed data and write the ML methodology.

## Person 2: Backend / data
- FastAPI endpoints and database.
- Upload validation, privacy handling, tests.
- Security hardening, auditability, API documentation.

## Person 3: Frontend / product
- Dashboard, analysis workbench, feedback explorer, insights, reports.
- Responsive design and accessibility checks.
- Demo script, screenshots, deployment instructions.

## Shared responsibilities
- Review fairness/privacy risks.
- Validate outputs with labeled examples.
- Prepare final report and presentation.
- Never present synthetic seed data or its metrics as real-world results.
